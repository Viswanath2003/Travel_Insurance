# DOMAIN RULES

- Every policy must belong to a base plan
- Add-ons are optional
- Policies are immutable after issuance
- Claims must reference policy snapshot
- Risk rules configurable by Admin
- Premium rules configurable by authorized users only
- Seasonal discounts supported
- Underwriting required for High and Very High risk
- Document versions must be stored
- Rule versions must be stored
- All actions audited
- RBAC mandatory
- Policy wording versioning mandatory
- Dynamic premium calculation mandatory
